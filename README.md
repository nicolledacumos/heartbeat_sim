# Crush Simulator
This project aims to demonstrate how a person's heartbeat might change around someone they like. It uses a proximity sensor that triggers 3 LEDs and sounds that represent a heartbeat, and as someone moves closer to the heart-shaped enclosure, the LEDs and sounds increase in speed. As someone moves away, the two elements slow down and regulate.

View the demo [here](https://youtu.be/dNY141XdHSo?si=Xpak-7sBcCtn6zWm)!
